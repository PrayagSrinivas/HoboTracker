# Quick Reference - UI Changes

## 🔍 Native Search
**Location:** DashboardView top  
**Usage:** Pull down or tap to reveal, type to filter habits by name

## 📅 View Mode Picker
**Location:** HabitDetailView toolbar (beside delete button)  
**Options:** Week | Month | Year  
**Style:** Menu (tap to open dropdown)

## 📊 Dynamic Progress Ring
**Updates based on view mode:**
- Week: X/7 days
- Month: X/31 days  
- Year: X/365 days

## 🗑️ Swipe to Delete
**Location:** DashboardView list  
**Gesture:** Swipe left on any habit  
**Options:** Full swipe to delete instantly OR partial swipe + tap Delete button

## 🎨 View Types

### Week View
- Current week bar chart
- 7 day boxes (Sun-Sat)
- Streak counter

### Month View  
- Full month calendar grid
- Circles for each day
- Today highlighted
- Weekday headers

### Year View
- 12 mini month grids
- 3x4 layout
- Tiny squares for days
- Perfect for pattern spotting
